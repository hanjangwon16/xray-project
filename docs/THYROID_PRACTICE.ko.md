# 실측 갑상선 단면 연습

초음파 촬영 연습에서 **갑상선 가이드 연습** 또는 **연습** 탭을 선택한다. 같은 사례의 3D 분할·현재 실측 단면·기준 영상을 함께 보면서 세 단계를 완료한다.

| 단계 | 사용자 행동 | 확인 근거 |
|---|---|---|
| 갑상선 찾기 | 현재 영상에서 갑상선 위치 선택 | 표시한 프레임의 같은 픽셀에서 분할 ID 1 확인 |
| 기준 0° 맞추기 | 위치·회전 조절 | 기준 원점과 3mm 이내, 빔의 진행·가로 축 방향 모두 8° 이내 |
| 90° 방향 비교 | 같은 위치에서 회전 | 같은 기준 위치, 90° 기준 축과 비교 |

기준 위치는 SegThy 001 왼쪽 갑상선 분할의 x·z 중심에서 정한다. 선형 표시 폭 50mm·깊이 55mm를 사용하며 연습 시작은 좌우 12%, 상하 -10% 이동한 위치다. 프레이밍은 기준 폭·깊이에서 각각 5mm 이내를 허용한다. 이 값은 웹 연습용 안내 범위이며 임상적으로 검증된 허용 오차가 아니다.

## 원신호와 좌표

기준 영상은 현재 영상과 동일한 `renderUltrasound`로 실측 볼륨을 삼선형 보간한다. 새 조직감·반사·혈류는 생성하지 않는다. 기준 프레임은 연습 시작과 기준 방향 변경 때만 계산하며 연속 조작 때 다시 계산하지 않는다. 현재 영상 계산은 기존 Worker가 담당한다.

0°·90°는 이 사례의 재구성 볼륨 축 기준이다. 임상 표준 단면이나 갑상선 장축·단축이라고 이름 붙이지 않는다. 원본 좌표가 전신 아틀라스에 정합된 것으로 표시하지 않는다.

판정은 화면에 표시한 프레임의 자세·분할을 사용한다. 설정과 표시 프레임이 다르거나 계산 중이면 선택·판정을 막는다. 픽셀 선택은 해당 프레임에만 유효하다. 프레임이나 선택이 바뀌면 이전 통과 결과를 무효화한다. 완료 기록은 현재 화면 세션에만 유지한다.

마우스·터치로 영상 위치를 선택할 수 있다. 키보드는 영상에 초점을 맞추고 방향키로 표시점을 이동한 뒤 Enter 또는 Space로 선택한다. 해설색 힌트는 원신호에 색을 덧씌우는 해설이며 평가 점수로 사용하지 않는다.

## 검증

- `node check-thyroid-practice.mjs`: 실제 분할을 이용한 키보드·터치 선택, 이전 선택 무효화, 잘못된 위치·180° 반전·기울임·접촉 해제·프레이밍 거부, 같은 원신호 기준 영상의 픽셀 해시, 세 단계 완료·재시작·자유 탐색 복귀, 화면 크기 1440/1024/390px.
- 기존 `check-acquired-ultrasound.mjs`, `check-ultrasound-expansion.mjs`, `check-probe-interaction.mjs`, `check-simulator.mjs`, `check-imaging-physics.mjs`: 실측 신호·전신·프로브·실제 영상 자료 회귀.
- `npm run build`: TypeScript와 정적 배포 빌드. 기존 vtk 번들 크기 경고는 남아 있다.

브라우저 검사는 `TEST_URL`을 지원하며 실제 Chrome을 사용한다. 자동 완료 검사는 구현 동작에 대한 검증이며 임상 정확도나 학습 효과에 대한 검증이 아니다.

로컬에서 위 검사와 빌드가 통과했다. 별도 `node bench-ultrasound.mjs`의 실측 갑상선 자유 탐색에서는 60회 연속 입력에 영상 60프레임이 갱신됐고, 화면 갱신 간격 p95 16.8ms·포인터 20회 이동 355ms였다. 현재 Mac의 Chrome에서 관찰한 값이며 휴대폰 성능이나 기존 버전 대비 향상 수치가 아니다.

## 다음 품질 단계의 작업 조건

1. **사례 기준 검수:** 전문가가 원본 볼륨에서 해부학적 축·식별 구조·목표 단면을 지정하고 검수 기록을 남긴다. 그 이후에만 임상 단면 이름과 허용 차이를 정한다.
2. **자세 대응 자료 확보:** 프로브 위치·회전과 영상 프레임이 함께 기록된 실제 스윕, 좌표계·보정 정보, 재배포 가능 라이선스를 확보한다. 독립 2D 이미지를 임의 자세의 정답으로 사용하지 않는다.
3. **조작별 검증:** 같은 부위에서 좌우·회전·기울임을 각각 변화시킨 실측 시퀀스와 비교한다. 위치·축 오차와 구조 식별 결과를 나눠 기록한다.
4. **압박·접촉 모델:** 압력 또는 변형과 동기화된 자료 없이 임의 영상 변형을 실제 압박 반응으로 주장하지 않는다. 자료 확보 후 별도 모델과 검증을 진행한다.
5. **사용자 시험:** 목표 구조 찾기와 기준 방향 맞추기에 필요한 시간·재시도·오인 구조를 관찰해 안내를 수정한다. 실제 저사양 기기와 터치 환경의 지연을 별도로 측정한다.

이번 변경은 단면 학습 흐름을 추가한 것이다. 전신 합성 영상의 조직감, 4mm 장기 표면, 다른 장기의 실측 3D 자료 부족은 해결하지 않았다.
