# 전신 팬텀·프로브 설정·실측 장기 자료 확장

## 적용 범위

전신 팬텀은 BodyParts3D의 피부·뼈·비장·양쪽 신장·위에 간·담낭·췌장·방광을 추가했다. 간은 원본 간 구역 메시를 합쳐 재료 영역으로 만들었다. 재료 간격은 4mm다. 신장 좌우와 전신 높이, 모든 장기의 유효 복셀 수를 검사한다. 환자 CT나 실측 초음파가 아니다.

브라우저에서 전신 볼륨마다 장기 표면을 다시 추출하던 작업을 전처리로 옮겼다. 피부는 12mm 정점 군집으로 줄여 선택에 사용하고, 나머지 표면은 재료 마스크를 평활화한 뒤 추출한다. 피부 표면과 복셀 접촉 사이의 오차는 복셀 간격에 따른 탐색 여유로 흡수한다. 정확한 체표 측정용이 아니다. 내부 장기는 기본 표시하며, 장기 선택은 위치 이동·회전 초기화·해당 부위 확대를 함께 실행한다. 전신 보기 버튼으로 전체 인체를 다시 볼 수 있다.

좌우/상하 슬라이더는 기존 피부 접촉 앵커를 해제하고 새 좌표의 앞쪽 체표를 찾는다. 몸 바깥에서는 접촉 해제한다. 현재 장기와 물리 위치(mm)를 영상 아래에 표시한다. 직접 피부 드래그는 선택한 체표의 법선을 사용한다. 영상과 3D는 같은 `probeGeometry`, `rayPoint`, `imagePoint`를 사용한다.

## 프로브 설정

| 설정 | 범위 | 결과 |
|---|---|---|
| 폭 | 15–70mm | 선형 영상의 실제 가로 범위, 곡면형의 접촉 폭과 가상 곡률 반경, 3D 프로브 폭 |
| 곡면 시야각 | 30–100° | 원호 모양 접촉면부터 퍼지는 빔의 각도와 가로 범위 |
| 영상 깊이 | 실측 15–85mm, 합성 40–220mm | 표본 위치·거리 눈금·화면 종횡비 |
| 젤 스탠드오프 | 0–30mm | 체표 앞에 결합층 간격을 두어 원점 이동. 공중으로 떼는 동작은 별도로 접촉 해제 |
| 주파수 | 합성에서 2–15MHz | 왕복 감쇠와 횡방향 빔 퍼짐의 교육용 근사 |
| Gain/TGC | 기존 범위 유지 | 밝기/깊이 보상. 실측은 Gain만 적용 |

곡면 반경은 `폭 / (2 sin(시야각/2))`다. 단면 변환은 이 가상 중심에서 각도와 깊이를 역산한다. 폭·각도·젤 간격 조합에서도 3D 빔과 영상 픽셀의 위치 일치를 검사한다.

빔 퍼짐은 파장 `1.54 / 주파수`(mm), 깊이, 폭으로 정한 제한된 이웃 광선 가중 평균이다. 개별 장비의 PSF나 집속·동적 구경을 보정한 모델이 아니다. 4mm 재료보다 작은 구조를 복원하지 못한다. 담낭·방광은 낮은 산란/감쇠의 유체 근사를 사용하지만 벽·내강·병변을 별도로 구분한 모델은 아니다.

실측 3DUS에서는 주파수로 새 영상을 만들지 않는다. 폭·시야각·시작 거리는 저장된 볼륨의 표시 범위를 바꾸며, 원본 표본에 삼선형 보간과 Gain만 적용한다. 원본 갑상선 신호와 라벨의 해시는 유지된다.

## 새로 확보한 실제 촬영 자료

| 자료 | 원본 확보 | 웹에 제공 | 이용 조건 |
|---|---:|---:|---|
| [Kaur & Singh, Kidney Ultrasound (2024)](https://data.mendeley.com/datasets/h6jc4xm4py/1) | 9,416장, ZIP 225,417,360바이트 | Normal/stone 원분류 각 8장, 총 16장 | CC BY 4.0 |
| [Chen & Zhou, LUS-7Seg (2026)](https://data.mendeley.com/datasets/cwc37g672d/1) | 10,507장 및 주석, ZIP 870,117,373바이트 | 7개 표준면 코드별 4장, 총 28장과 장기 마스크 | CC BY 4.0 |

전체 원본 두 ZIP을 로컬 `data/sources/`에 보관하고 Git에는 넣지 않는다. 배포 파일은 선택한 44장의 JPEG를 원본 그대로 복사한다. LUS의 `肝脏`/`Live`는 간, `胆囊`/`GB`는 담낭으로 매핑하고 원본 다각형을 마스크로 변환한다. 간은 적갈색, 담낭은 녹색이다. 단면 코드의 확장 이름은 확인되지 않아 코드 그대로 제공한다. 표본 선정은 폴더별 정렬 순서에 따르며 임상적 대표성이나 난이도를 보장하지 않는다.

`web/public/learning/organ-sources.json`은 원본 주소·버전·배포처 SHA256·원본 멤버 경로·배포 이미지 해시를 기록한다. 원본 ZIP은 배포처 해시와 일치해야 변환을 진행한다. 출처와 CC BY 링크, 변환 사항은 자료 화면에 표시한다. 기존 유방 6장 및 X-ray 8장을 포함하면 웹 자료는 총 58장이다.

신장·간·담낭 프리셋의 ‘실제 … 참고 영상’은 해당 장기 필터의 자료 화면으로 연결한다. 2D 영상에는 추적 좌표와 촬영 방향/주파수 메타데이터가 없으므로 전신 팬텀의 위치나 입사각과 연동하지 않는다. 실측 다기관 영상을 전신에서 임의 각도로 얻는 기능은 아직 없다. 갑상선만 실제 3DUS를 재단면한다.

## 재현·검증

```sh
.venv/bin/python scripts/prepare_anatomical_phantom.py
.venv/bin/python scripts/prepare_organ_ultrasound.py
cd web
node check-imaging-physics.mjs
TEST_URL=http://127.0.0.1:4194 node check-ultrasound-expansion.mjs
TEST_URL=http://127.0.0.1:4194 node check-probe-interaction.mjs
TEST_URL=http://127.0.0.1:4194 node check-acquired-ultrasound.mjs
TEST_URL=http://127.0.0.1:4194 node check-simulator.mjs
npm run build
```

브라우저 검사는 별도로 실행 중인 개발 서버와 설치된 Chrome을 사용한다. 확장 검사는 44개 이미지 해시, 4개 추가 장기 선택, 좌우·폭·각도·주파수·간격 변경의 영상 차이, 실제 장기 필터와 마스크, 화면 넘침과 JS 오류를 확인한다.

로컬 Chrome 1440×960의 전신 모드 측정: 초기 표시 1,567ms, 회전 입력 60회 중 결과 갱신 29회, 화면 프레임 간격 p95 16.7ms, 20회 피부 드래그 781ms. 선택용 피부 축소 전의 같은 검사에서는 1,669ms였다. 이는 이 컴퓨터의 자동 입력 결과이며 저사양 모바일 성능을 보장하지 않는다. `US_SOURCE=anatomy node bench-ultrasound.mjs`로 반복할 수 있다.

## 실측 시뮬레이터로 확장하기 위한 작업 조건

다음 데이터는 실제 장기별 추적 3DUS와 동일 사례 분할이어야 한다. 라이선스뿐 아니라 동봉 이용계약과 웹 재배포 허용을 함께 확인한다. 원점·간격·방향행렬·추적 좌표계를 원본과 함께 보존하고, 전신과 정합한 근거가 없는 장기는 같은 환자 위에 배치하지 않는다. 각 장기에서 획득 범위를 벗어난 이동은 빈 영역과 범위 안내로 처리한다.

주파수·프로브별 실제 차이를 제공하려면 같은 대상/위치를 여러 주파수·구경·거리에서 획득한 영상이나 RF/IQ 채널 신호, 장비 응답과 보정값이 필요하다. 현재 자료의 해상도를 늘리거나 노이즈를 덧씌워 이를 대체하지 않는다. 이후 집속·압박·굴절·혈류를 추가하려면 각각의 검증용 팬텀 측정과 물성/변형 경계조건이 필요하다.
