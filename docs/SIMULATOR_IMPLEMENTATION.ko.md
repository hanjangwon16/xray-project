# 인체와 영상 시뮬레이터 구현 상태

## 현재 작동하는 학습 흐름

웹의 **초음파 촬영 연습 → 전신 인체 팬텀**이 기본 진입점이다. BodyParts3D의 실제 전신 피부 메시를 표시한다. 기본 `밀기` 모드에서 피부를 누른 채 움직이면 탐촉자가 표면을 따라 이동한다. 보이는 피부 삼각형의 위치·법선으로 앞면·옆면·후면의 접촉과 안쪽 스캔 방향을 계산한다. 몸 밖으로 끌면 접촉이 끊기고 B-mode가 비며, 피부에 다시 대면 회복한다. 피부와 4mm 재료 격자 차이는 안쪽으로 최대 3 voxel + 2mm까지 접촉점을 탐색해 보정한다.

| 손동작 모드 | 드래그 동작 |
|---|---|
| 밀기 | 피부 위 이동, 몸 밖에서 접촉 해제 |
| 회전 | 좌우 이동으로 탐촉자 축 회전 |
| 앞뒤 기울임 | 상하 이동으로 기울이기, ±35도 |
| 좌우 기울임 | 좌우 이동으로 기울이기, ±35도 |
| 화면 회전 | 카메라 회전, Alt 드래그로 화면 이동 |

마우스와 터치 pointer 조작을 지원한다. Shift 또는 우클릭 드래그로 화면 회전을 바로 사용할 수 있고, 휠은 확대다. 전신 보기 / 탐촉자 확대 / 내부 장기 보기로 외형과 내부 위치를 연결한다. 기존 수치 슬라이더와 장기 프리셋도 유지한다. 좌우/상하 슬라이더와 프리셋은 앞면 기준으로 돌아간다. 영상 정지 중 직접 자세 조작도 잠긴다.

계산은 한 건 실행과 최신 자세 한 건 대기로 제한한다. 연속 동작 중에도 완료된 프레임을 표시하고 놓으면 최종 자세로 수렴한다. 예전처럼 조작이 멈출 때까지 계산을 미루지 않는다. 데이터 교체 시 이전 worker 결과는 버린다.

세 데이터 모드는 서로 다른 의미를 갖는다.

| 모드 | 인체·영상 데이터 | 가능한 학습 | 제한 |
|---|---|---|---|
| 전신 인체 팬텀 | BodyParts3D 피부·뼈·신장·비장·위 메시 | 전신 위치, 탐촉자 방향과 단면 관계 | 4mm 재료 격자. 나머지 내부는 일반 연부조직. 환자 CT 아님 |
| 실제 복부 CT 기반 | TotalSegmentator example_ct와 같은 격자의 분할 | CT 구조에 대한 음향 근사, 동일면 CT 비교, 같은 사례 CT/X-ray 이동 | 복부만 포함. CT에서 초음파를 정확히 복원한 것이 아님 |
| 실측 시험 팬텀 | PLUS의 실측 3D 초음파 볼륨 | 실측 신호를 다양한 면으로 재단면 | 인체 아님. 각도에 따른 새 음향 신호를 생성하지 않음 |

실제 영상 자료에서는 FracAtlas X-ray 8장, BUS-BRA 유방 초음파 6장과 병변 마스크를 원본 픽셀로 비교한다. 시뮬레이터와 다른 사람의 영상이며, 시점별 연속 볼륨으로 사용할 수 없다. 데이터셋 표기는 개별 임상 검수와 구분해 표시한다.

## 데이터 준비와 재현

- `scripts/fetch_imaging_sources.py`: 원본 확보·크기·해시 기록. 원본 ZIP은 로컬 `data/sources/`에 보관하며 배포하지 않는다.
- `scripts/prepare_simulator_assets.py`: 표본 영상·출처·PLUS uint8 볼륨을 추출한다. FracAtlas 중복 ID 2개는 제외한다.
- `scripts/prepare_anatomical_phantom.py`: Python 환경의 numpy, scipy, trimesh 4.12.2를 사용한다. `data/bodyparts3d/isa.zip`과 기존 atlas 뼈 메시가 필요하다.
- 전신 피부 FJ2810의 원래 삼각형을 보존한다. 신장 FJ3147/FJ3145, 비장 FJ2561, 위 FJ2564를 같은 좌표로 변환한다. 원 좌표에서 `(-x,-y,z)`로 RAS를 만들고 양쪽 신장 위치를 확인한다.
- 피부 메시의 열린 틈 때문에 단순 3D fill로 내부가 채워지지 않아, 4mm 격자에서 축상 단면 closing 2회와 hole fill을 적용한다. 이는 피부 아래 재료를 채우는 근사이며 피부 표시 메시 자체는 변경하지 않는다. 장기·뼈를 그 내부로 제한한다.
- 결과는 173×79×436 재료 볼륨이다. 장기 잔존 수: 오른쪽 신장 2,327, 왼쪽 2,263, 비장 2,248, 위 10,602 voxel. 재료 볼륨 해시와 라이선스는 배포 폴더의 case.json / ATTRIBUTION.txt에 있다.
- BodyParts3D 원본에 포함된 이용 고지와 파생물 조건을 유지한다. PLUS BSD-3-Clause와 BUS-BRA 원본 고지를 함께 배포한다. 이용 동의가 필요한 TRUSTED 임상 영상은 포함하지 않는다.

## 계산 및 검증

`ultrasound.ts`의 동일한 geometry 함수를 3D 스캔면과 영상 생성에 사용한다. 교육용 음향 임피던스 경계 반사, 왕복 감쇠, 주파수·gain·TGC와 공간에 고정된 산란을 근사한다. 실제 조직 물성을 교정한 값은 아니다. CT HU를 B-mode 밝기로 그대로 표시하지 않는다. 복부 모드의 CT 비교 버튼만 원 CT의 같은 면을 표시한다.

`drr.ts`와 `beam.ts`는 3D 빔과 X-ray 투영 좌표를 공유한다. 프레임별 자동 min/max 대신 고정 감쇠 window를 사용해 두께에 따른 밝기 차이를 유지한다. 산란·검출기 응답·임상 선량 교정은 없다.

```sh
cd web
npm run build
node check-imaging-physics.mjs
npm run dev -- --host 127.0.0.1 --port 4190
# 별도 터미널, 설치된 Chrome 사용
node check-simulator.mjs
node check-probe-interaction.mjs
```

수치 검사는 좌표 직교성, 3D/영상 일치, 보간, 고정 산란, 뼈 음영, 주파수 감쇠, gain, 비접촉 빈 영상, 실측 팬텀 보간, DRR 두께 차이를 확인한다. 브라우저 검사는 전신 인체와 피부 클릭, 내부 보기, 자세 변경, freeze/reset, 데이터 모드 교체, 동일 사례 CT 이동, 원영상·마스크, 화면 크기별 넘침과 반복 종료를 확인한다.

## 상용 시뮬레이터로 올리기 위한 후속 작업 명세

1. **해부 재료 확장:** 같은 인체의 완전한 간·폐·혈관·근육 분할을 확보하고 원 좌표를 보존한다. 다른 사람의 영상과 atlas를 단순히 같은 좌표라고 합치지 않는다. 실제 CT와 3DUS의 대응이 필요한 경우 동일 대상의 등록 오차를 측정한다.
2. **탐촉자 접촉:** 표면 법선 기반 앞면·옆면·후면 접촉과 비접촉을 구현했다. 후속으로 접촉 면적·입사각에 따른 결합 손실과 압박에 따른 조직 변형을 구현한다. 현재 피부 접촉은 하나의 접촉점 근사이며, 힘 센서나 조직 압박을 재현하지 않는다. 검증은 표면 거리·법선·접촉 실패·장기 이동량으로 한다.
3. **음향 모델:** PyMUST 등 확보한 연구 코드를 별도 검증 환경에서 실행하고 조직별 파라미터·주파수·점확산·스펙클·음영을 실측 팬텀과 비교한다. 현재 모델에 복잡한 효과가 이미 있는 것처럼 표시하지 않는다. LGPL 등 재배포 조건을 검토한 후 서버 또는 브라우저 구성 방식을 정한다.
4. **X-ray 교육:** 전신 환자 CT와 구조 분할을 확보한 후 촬영 부위별 collimation·중심선·관절 자세·확대·회전 오차 과제를 만든다. 단일 복부 CT에서 전신 X-ray를 생성하지 않는다. 현재 표본 정지 영상은 비교 자료로만 사용한다.
5. **교수 검수:** 방사선사·초음파 실무자가 목표 단면과 오답 동작을 정의하고, 처음 보는 사용자가 안내 없이 목표 단면을 찾을 수 있는지 관찰한다. 전문가 검수·사용성·영상 타당성을 통과하기 전에는 임상 수준이라고 판매하지 않는다.
6. **배포 성능:** 실제 보급형 노트북·태블릿에서 초기 로딩, 조작 지연, GPU 메모리를 측정한다. 현재 vtk 번들 약 1.5MB의 경고가 있으며, 대형 atlas 메시의 최초 전송 비용도 별도 최적화 대상이다.

GitHub Pages는 main push 시 기존 Actions가 web/dist를 빌드·배포한다. 원본 데이터 ZIP, .venv, .dryforge, 사용자 문서와 이미지는 배포 대상에서 제외한다.
