# 초음파 화면 자체 점검과 개선

## 확인한 문제와 반영

| 문제 | 변경 |
|---|---|
| 설정이 길게 늘어져 방향·영상 조절을 찾기 어려움 | 위치·방향·영상 탭, 소스 선택 2열 배치 |
| 장기 선택 후 움직이면 선택 표시와 실제 영상 링크가 사라짐 | 학습 대상과 현재 자세를 분리해 선택·참고 링크 유지 |
| 뼈와 다른 장기에 가려 선택 장기를 구별하기 어려움 | 선택 장기 강조: 주변 구조 투명도 조절, B-mode 신호 보존 |
| 3D·단면 해설색이 다름, 전신 담낭·방광이 CT 부신 색을 사용함 | 소스별 공통 색상으로 3D·해설색·장기 버튼 연결 |

학습 대상은 현재 빔에 실제로 포함된 장기라는 뜻이 아니다. 위치 이동 후에는 단면 아래에 자유 스캔과 현재 좌표를 표시한다. 실제 영상 자료는 다른 환자의 2D 참고 영상이다.

## 검증

- `npm run build`: TypeScript·배포 빌드.
- `node check-imaging-physics.mjs`: 실측 신호 무변조·좌표·합성 모델 회귀.
- `node check-ultrasound-expansion.mjs`: 키보드 탭 전환, 패널 하나 표시, 선택 유지, 장기 강조 전후 3D 변화와 B-mode 동일성, 해설색 해제 시 신호 복귀, 장기별 실제 참고 자료.
- `node check-acquired-ultrasound.mjs`: 실측 갑상선·해설색·회전·정지·초기화·3개 화면 크기.
- `node check-probe-interaction.mjs`: 연속 이동·회전·기울임·접촉·후면·터치.
- `node check-simulator.mjs`: 소스 전환·CT 연계·실제 영상 자료·반복 해제.

브라우저 검사는 `TEST_URL`로 로컬 또는 공개 배포 주소를 지정한다. 실제 Chrome에서 데스크톱·태블릿·모바일 크기의 화면을 확인했다. 모바일 크기 검사는 실제 저사양 휴대폰의 성능 검증을 대신하지 않는다.

2026-10-15 로컬 검사: 위 6개 명령이 통과했다. `US_SOURCE=anatomy node bench-ultrasound.mjs`에서는 초기 로딩 1,494ms, 60회 입력 중 영상 29프레임 갱신, 화면 갱신 간격 p95 16.8ms, 피부 위 포인터 20회 이동 867ms를 관찰했다. 기존 버전과 같은 환경에서 비교한 속도 향상 수치는 아니다. 빌드는 기존 vtk 번들 크기 경고를 출력한다.

## 남은 핵심 한계

전신 모델의 재료 격자는 4mm이며 장기 표면과 합성 조직감이 거칠다. 실측 3D 초음파는 갑상선의 제한된 촬영 범위뿐이다. 다른 장기의 실제 2D 영상에는 프로브 자세 추적 정보가 없어 현재 전신 자세에 맞는 실측 영상으로 변환할 수 없다. 이를 해결하려면 부위별 추적 3D/자유주행 초음파 또는 자세가 기록된 연속 스윕 자료가 필요하다.
